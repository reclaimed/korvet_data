# Файлы данных для эмулятора Корвет ПК8020

Файлы данных для эмуляции советского персонального компьютера **Корвет ПК8020** — 8-разрядной ЭВМ, выпущенной в 1985 году в **НИИ ядерной физики МГУ** (НИИЯФ МГУ), СССР.

В этом репозитории собраны образы ПЗУ, образы дискет, шрифты, звуковые сэмплы и профили принтеров для использования с эмуляторами Корвет ПК8020.

## Структура репозитория

```
data/
├── rom/        # Образы ПЗУ и шрифты
├── kdi/        # Образы дискет (.kdi)
├── sounds/     # Звуки работы НГМД (.wav)
└── vprinter/   # Шрифты виртуального принтера (.mpf)
```

## Содержимое

### `data/rom/` — Образы ПЗУ и шрифты

| Файл | Описание |
|------|----------|
| `korvet_v1.1.rom` | ПЗУ Корвет версии 1.1 |
| `korvet_v2.0.rom` | ПЗУ Корвет версии 2.0 |
| `kontur_v1.0.rom` | ПЗУ Контур версии 1.0 |
| `cpm22_shkomp.rom` | ПЗУ CP/M 2.2 "CP/M-80 v.2.2 SHCOMP BIOS Ver.1.0 1991" |
| `korvet.fnt` | Шрифт видеогенератора (Корвет) |
| `kontur.fnt` | Шрифт видеогенератора (Контур) |
| `mapper.mem` | Таблица маппера памяти |

### `data/kdi/` — Образы дискет

Образы дискет в формате `.kdi` с программным обеспечением для CP/M 2.2:

| Файл | Описание |
|------|----------|
| `disk__system.kdi` | Системная дискета (PROFFER, PCTOOLS, POWER, BASIC, форматировщики, копировщики, утилиты CP/M, утилиты для принтеров, архиваторы, утилиты локальной сети, и проч.)|
| `disk_games1.kdi` | Сборник игр №1 |
| `disk_games2.kdi` | Сборник игр №2 |
| `disk_abris.kdi` | Графический редактор «Абрис»|
| `disk_musworld.kdi` | Нотный редактор Music World |
| `disk_e87.kdi` | Е-практикум 87 |
| `disk_asm.kdi` | Ассемблер |
| `disk_epascal.kdi` | Компилятор Express Pascal |
| `disk_fortran.kdi` | Компилятор Fortran |
| `disk_e_editor.kdi` | Текстовый процессор E и утилита печати FX |
| `disk_chiworker.kdi` | Текстовый процессор ChiWriter |
| `disk_supertext.kdi` | Текстовый процессор SuperText |
| `disk_supercalc.kdi` | Электронная таблица SuperCalc |
| `disk___empty_cpm22_niiyaf12.kdi` | Пустая системная дискета CP/M 2.2 (НИИЯФ, версия 1.2) |

Полный список файлов доступен в `data/kdi/kdi_files_list.txt`.

### `data/sounds/` — Звуки работы НГМД

Аутентичные звуки привода 5,25" (WAV) для эмуляции работы дисковода:

- Звуки позиционирования головки с разным временем: `525_seek_2ms.wav`, `525_seek_6ms.wav`, `525_seek_12ms.wav`, `525_seek_20ms.wav`
- Вращение шпинделя: `525_spin_empty.wav`, `525_spin_loaded.wav`, `525_spin_end.wav`
- Раскрутка шпинделя: `525_spin_start_empty.wav`, `525_spin_start_loaded.wav`
- Шаг головки: `525_step_1_1.wav`

Звуки взяты из [https://github.com/mamedev/mame](MAME).


### `data/vprinter/` — Профили виртуального принтера

Шрифты для виртуального 9-игольчатого принтера:

| Файл | Кодировка |
|------|-----------|
| `printer_9dot.mpf` | По умолчанию |
| `printer_9dot_gost.mpf` | ГОСТ |
| `printer_9dot_866.mpf` | CP866 |
| `printer_9dot_koi8.mpf` | КОИ-8 |

## Лицензия

Права на оригинальное программное обеспечение принадлежат их правообладателям (НИИЯФ МГУ, советским разработчикам и т. д.). Файлы предоставлены в целях **сохранения исторического наследия и в образовательных целях**.
